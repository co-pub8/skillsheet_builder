# スキルシート自動生成

## セットアップ
    pip install -r requirements.txt

## 使い方
1. `data.yaml` を編集する（内容はここだけ。初めての場合は `data.sample.yaml` をコピーして作成）
2. `python build.py --pdf` を実行
3. `output/【技術者コード】スキルシート_YYYYMM.docx / .pdf` が出力される

| オプション | 説明 |
|---|---|
| `--pdf` | PDFも出力（LibreOffice、または Word＋docx2pdf） |
| `--as-of 2026-10` | 作成年月と「現在」の基準月を指定（省略時は今月） |
| `--tags 通信,組込み` | 指定したタグを持つプロジェクトだけを出力 |
| `-d other.yaml` | 別のデータファイルを使う |

## 期間の数え方
`data.yaml` の `duration_mode` で切り替えます。
- `inclusive`（既定）: 開始月と終了月の両方を数える　例: 2019年4月～5月 = 2ヶ月
- `exclusive`: 差で数える　例: 2019年4月～5月 = 1ヶ月
- 個別に上書きしたい場合は、プロジェクトに `duration: "1ヶ月"` と書く

## レイアウトを変えたいとき
`template.docx` を Word で直接編集してください（罫線・色・フォントなど）。
`{{ }}` や `{%p ... %}` は差し込み用のタグなので、消さないでください。
タグを新しく書くときは、メモ帳で書いてから一度に貼り付けてください（Wordが入力途中で文字を分割するのを防ぐため）。

`tools/make_template.py` は、元のスキルシートから template.docx を作った変換スクリプトです（通常は使いません）。

## 注意（Wordで開けなくなるのを防ぐため）
- `w:vMerge` や `w:jc` など、XMLの**属性値**には `{% %}` を書かないでください。
  Word は属性値を厳密にチェックするため、ファイルが開けなくなります。
  スキル表の縦結合と「-」の中央揃えは、build.py の `postprocess()` で差し込み後に設定しています。
- タグを書いてよいのは、**本文の文字**か、**段落・行だけに書く `{%p %}` / `{%tr %}`** だけです。
